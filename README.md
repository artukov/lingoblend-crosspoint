# LingoBlend plugins for CrossPoint Reader — moved

This repository is archived. The plugins now live in CrossPoint's **Plugin Hub**,
one repository each:

| Plugin | Repository |
|---|---|
| LingoBlend | [artukov/lingoblend.crosspoint-plugin](https://github.com/artukov/lingoblend.crosspoint-plugin) |
| LingoBlend Dictionaries | [artukov/lingoblend-dict.crosspoint-plugin](https://github.com/artukov/lingoblend-dict.crosspoint-plugin) |

On the reader: **Home → Plugins → Plugin Hub → Community Plugins**. Setup, and
installing by USB instead: [lingoblend.app/crosspoint](https://www.lingoblend.app/crosspoint).

The files here stay readable so existing links keep working, but they are
frozen at LingoBlend 1.1.0 and LingoBlend Dictionaries 1.2.0 and no longer
updated. Installs from Plugin Hub update in place and keep your sign-in.
